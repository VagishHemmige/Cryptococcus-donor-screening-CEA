Shape parameters

The list shape_parameter sets how widely each parameter varies in the sensitivity analyses. Probabilities have Beta priors: the shape parameter is \(\alpha\), and \(\beta = \alpha(1 - \mu)/\mu\), so the prior mean equals the base-case value \(\mu\). Costs and QALYs have gamma priors: the shape parameter is \(k\), and the scale is \(\theta = \mu/k\). A shape of NA fixes the parameter at its base-case value.

## Parameter summary

The table below is computed from the code above when the page is rendered. The 95% interval is the 2.5th to 97.5th percentile of each prior distribution. The evidence for each value is reviewed on the [evidence base](../references/literature-review.md) page.

```{r}
#| label: parameter-table
#| echo: false
parameter_summary <- tibble::tibble(
  parameter = names(expected_value),
  value = unlist(expected_value),
  shape = vapply(
    names(expected_value),
    function(p) if (is.null(shape_parameter[[p]])) NA_real_ else shape_parameter[[p]],
    numeric(1)
  )
) |>
  dplyr::mutate(
    family = dplyr::case_when(
      parameter == "number_donors" ~ "Label",
      is.na(shape) ~ "Fixed",
      startsWith(parameter, "p_") ~ "Beta",
      TRUE ~ "Gamma"
    ),
    lb_95 = dplyr::case_when(
      family == "Beta" ~ qbeta(0.025, shape, shape * (1 - value) / value),
      family == "Gamma" ~ qgamma(0.025, shape = shape, scale = value / shape),
      TRUE ~ NA_real_
    ),
    ub_95 = dplyr::case_when(
      family == "Beta" ~ qbeta(0.975, shape, shape * (1 - value) / value),
      family == "Gamma" ~ qgamma(0.975, shape = shape, scale = value / shape),
      TRUE ~ NA_real_
    )
  )

parameter_summary |>
  gt::gt() |>
  gt::fmt_number(columns = value, decimals = 4, drop_trailing_zeros = TRUE) |>
  gt::fmt_number(columns = c(lb_95, ub_95), n_sigfig = 3, drop_trailing_zeros = TRUE) |>
  gt::sub_missing(missing_text = "\u2014") |>
  gt::cols_label(
    parameter = "Parameter",
    value = "Base-case value",
    shape = "Shape",
    family = "Distribution",
    lb_95 = "Lower 95%",
    ub_95 = "Upper 95%"
  ) |>
  gt::tab_style(
    style = gt::cell_text(font = "monospace"),
    locations = gt::cells_body(columns = parameter)
  )
```

`number_donors` labels the tree diagram's starting cohort and is not varied in the sensitivity analyses. The willingness-to-pay threshold used for net monetary benefit is \$`r format(wtp, big.mark = ",", scientific = FALSE)` per QALY, and the probabilistic sensitivity analysis uses `r format(nsim, big.mark = ",", scientific = FALSE)` draws.
