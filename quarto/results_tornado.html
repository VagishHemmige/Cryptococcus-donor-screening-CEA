One-way sensitivity analyses (tornado diagrams)

Author
Affiliation

Vagish Hemmige

Albert Einstein College of Medicine

The code behind these results is on the Sensitivity analyses page. Sensitivity analyses explained describes how to read a tornado diagram. All numbers are per potential donor and are read from the output of the most recent model run.

Parameters of the model

The parameters are the same as for the probabilistic sensitivity analysis. We utilize the means, and vary the parameters according to the 95% intervals in the appropriate tables.

Tornado diagrams

Tornado diagram for costs

We see that costs are most sensitive to assumptions regarding the cost of an episode of cryptococcal disease post-transplant, cost_disease, and the probability that a donor has cryptococcus, p_donor_cryptococcus.

The expected cost savings from screening, as predicted, increase (become more negative) if those parameters lie at the higher end of the 95% interval.

Tornado diagram for QALYs

We see that QALYs are most sensitive to assumptions regarding the specificity of cryptococcal screening, p_specificity, because each false-positive screen in a donor without cryptococcus can lead to a cancelled transplant.

As predicted, higher values of specificity will lead to less QALY loss from screening. Probability of donor cryptococcus, p_donor_cryptococcus has surprisingly little effect on QALYs.

The QALY gain from a transplant, q_nocryptococcus, is the second-largest driver of QALYs. Its range, from 1.5 to 12.1 QALYs, comes from the shared gamma shape parameter rather than from evidence, and its upper end is likely to be implausibly high for the gain from a single transplant; the evidence review discusses plausible values.

Which inputs change the decision?

The decision depends on net monetary benefit, which combines cost and QALYs. The table ranks the inputs by how much net monetary benefit changes across each input’s range (base case: −$3,837.18 per potential donor).

Input Low value High value NMB at low value NMB at high value
p_specificity 0.853 1 −$27,803.81 −$64.86
q_nocryptococcus 1.5 12.1 −$962.92 −$8,545.68
p_usage 0.241 0.631 −$2,148.70 −$5,627.43
p_cancelled 0.549 0.962 −$2,623.08 −$4,620.05
q_loss_cryptococcus 0.681 5.48 −$3,898.49 −$3,736.74
p_donor_cryptococcus 0.00048 0.00171 −$3,806.44 −$3,879.01

No single input changes the conclusion across its range. Net monetary benefit stays negative at both ends of every input’s range. The closest is p_specificity, where it reaches −$64.86 at one end.

Two cautions apply. Each input is varied alone, so inputs that are uncertain together can move the result further than any one bar; the probabilistic sensitivity analysis varies them all at once. And the width of each range comes from shared shape parameters, not from the evidence for that input, as explained on How the inputs are chosen.

```{r}
#| label: read-tornado
#| include: false
tornado <- read.csv("../output/tornado_results.csv")
base <- read.csv("../output/base_case_results.csv")
money <- function(x, accuracy = 0.01) {
  paste0(if (x < 0) "\u2212" else "", "$", formatC(abs(x), format = "f", digits = max(0, -log10(accuracy)), big.mark = ","))
}
qaly <- function(x, digits = 4) paste0(if (x < 0) "\u2212" else "", formatC(abs(x), format = "f", digits = digits))
varied <- tornado[tornado$range_nmb > 0, ]
varied <- varied[order(-varied$range_nmb), ]
top <- head(varied, 6)
input_value <- function(p, x) if (startsWith(p, "cost_")) money(x, 1) else format(signif(x, 3), scientific = FALSE, big.mark = ",")
crosses <- varied$parameter[(varied$nmb_difference_low > 0) != (varied$nmb_difference_high > 0)]
best <- varied[which.max(pmax(varied$nmb_difference_low, varied$nmb_difference_high)), ]
qaly_order <- tornado$parameter[order(-tornado$range_qaly)]
qaly_rank <- match("q_nocryptococcus", qaly_order)
qaly_rank_text <- if (qaly_rank == 1) "the largest driver of QALYs" else paste0(c("", "the second-largest", "the third-largest")[min(qaly_rank, 3)], if (qaly_rank > 3) paste0("ranked ", qaly_rank, " of the drivers") else " driver of QALYs")
```

### Tornado diagram for QALYs

![](../figures/tornado_qaly.svg)

Its range, from `r input_value("q_nocryptococcus", tornado$lb_95[tornado$parameter == "q_nocryptococcus"])` to `r input_value("q_nocryptococcus", tornado$ub_95[tornado$parameter == "q_nocryptococcus"])` QALYs, comes from the shared gamma shape parameter rather than from evidence, and its upper end is likely to be implausibly high for the gain from a single transplant; the [evidence review](../references/literature-review.md) discusses plausible values.
